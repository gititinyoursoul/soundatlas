Here’s a generalized documentation version of the **final route copy + presentation treatment** stage.

# Final Route Copy + Presentation Treatment

## Goal

Turn an evidence-reviewed route into the final user-facing experience.

At this stage, the historical research, route cohort, thesis, and narrative structure are stable.

The task is now to coordinate two layers:

* **final route copy**
* **map and visual presentation**

The copy should communicate the essential argument clearly and concisely.

The presentation layer should carry spatial, visual, and structural information that does not need to be repeated in prose.

## Inputs

A route that has already passed:

* deep route research
* cross-stop synthesis
* narrative drafting
* evidence review

The route should already have:

* a stable event cohort
* defensible claims
* a working thesis
* narrative sections
* transition logic
* identified uncertainties
* source support

## Core Principle

Do not treat final copy and map presentation as separate products.

They should divide the explanatory work between them.

The question is:

> **What should the user read, and what should the map or visual layer show instead?**

This often allows the final prose to become shorter and clearer.

## Part 1: Final Route Copy

### 1. Preserve evidence-reviewed meaning

Do not reintroduce claims that were removed or softened during evidence review.

Final editing may improve:

* rhythm
* clarity
* length
* structure
* tone

but should not strengthen historical certainty without new evidence.

### 2. Shorten research prose into route prose

Research drafts often explain too much because they need to establish reasoning.

Final route copy should retain only what the user needs to understand the story.

Remove:

* repeated historical justification
* research-process commentary
* source-quality discussion
* unnecessary caveats already handled by wording
* details that can be shown visually

Preserve:

* essential facts
* historical agency
* narrative function
* transitions
* thesis-relevant interpretation

### 3. Give every stop a clear narrative function

Each stop should quickly answer:

* What happened here?
* Who acted?
* What changed?
* Why does this matter to the larger route?

Avoid turning stops back into general venue biographies.

### 4. Use concise stop framing

A useful event structure is:

**Stop title**

* place / event
* date

**Short narrative hook**

* what changes here

**Event explanation**

* key evidence-supported facts

**Narrative significance**

* what this adds to the route

The significance should connect to the route thesis rather than merely state that the location was important.

### 5. Keep parallel developments parallel

If several events represent simultaneous or independent developments, preserve that relationship in the prose.

Avoid transitions such as:

> Next, this led to...

when the research established only simultaneity.

Prefer:

> At the same time...

> Elsewhere in the city...

> Another version was developing...

### 6. Keep the conclusion proportional

The final paragraph should resolve the route thesis without claiming total historical coverage.

Avoid:

> These six places created the genre.

Prefer:

> Together, these events reveal several ways the culture was changing.

The conclusion should reflect the route's actual evidentiary scope.

## Part 2: Presentation Treatment

### 7. Decide what the map should explain

The map should do more than show where events occurred.

Identify which historical relationships are best communicated spatially.

Possible functions include:

* isolation
* clustering
* simultaneous development
* movement
* geographic contrast
* expansion
* network formation
* convergence

Each presentation moment should have a clear analytical purpose.

### 8. Use progressive map storytelling

Do not necessarily show every route point from the beginning.

Reveal geography as the narrative develops.

A common structure is:

**Opening**

* establish city and timeframe

**Foundation**

* show one initial location

**Expansion**

* reveal multiple simultaneous locations

**Network**

* retain earlier locations while introducing connections

**Convergence**

* emphasize a later node where several route themes become visible together

**Conclusion**

* reveal the full geography

This lets the map mirror the narrative argument.

### 9. Visualize simultaneity deliberately

When several events represent parallel developments, reveal them together.

Do not use sequential animations or connecting arrows if those would imply unsupported causation.

Instead, differentiate the events through:

* icons
* labels
* artifact types
* conceptual graphics
* spatial grouping

The visual language should communicate:

> These things were happening at the same time in different ways.

### 10. Assign conceptual graphics to historical mechanisms

A map marker can communicate more than location.

Possible visual languages include:

**Ownership / organizing**

* venue
* promoter
* business iconography

**Dance practice**

* dancers
* movement patterns
* social-dance imagery

**Technology**

* turntables
* speakers
* lighting

**Distribution**

* records
* labels
* network diagrams

**Community**

* membership
* gathering
* social-space imagery

The graphic should represent the event's historical function, not merely decorate it.

### 11. Introduce connections only when evidence supports them

Arrows are especially powerful and therefore risky.

Use arrows for:

* documented movement
* distribution networks
* known influence
* migration
* circulation

Do not use arrows simply because two route stops belong in the same story.

A route line can imply causality even when the prose does not.

### 12. Match visual grammar to route shape

Different historical structures require different map treatments.

**Linear route**

* sequence or directional line

**Parallel development**

* simultaneous reveal

**Network**

* nodes and connections

**Contrast**

* paired or differentiated locations

**Convergence**

* several earlier visual elements reappearing together

**Migration**

* directional movement

The visual grammar should express the same historical model established during synthesis.

### 13. Use artifacts strategically

For each stop, identify one supporting visual type that reinforces its narrative role.

Examples:

* flyer
* invitation
* photograph
* dance image
* membership card
* floor plan
* record
* newspaper clipping
* poster
* technical diagram

Do not overload every stop with every available artifact.

Choose the artifact that best helps explain the event.

### 14. Let visual explanation reduce prose

If the map clearly shows that three events occurred simultaneously across different parts of the city, the text does not need to repeatedly explain their geographic separation.

If a diagram shows a distribution loop, the prose can describe its historical meaning rather than every mechanical step.

The map and copy should complement rather than duplicate one another.

### 15. Design the opening and ending as route-level moments

The opening should establish:

* topic
* place
* timeframe
* central question or transformation

The ending should reveal the full route structure and allow the user to understand the larger pattern.

These moments may use the entire map differently from individual event stops.

## Suggested Presentation Storyboard

| Narrative moment     | Map state                                | Visual support           | User takeaway                               |
| -------------------- | ---------------------------------------- | ------------------------ | ------------------------------------------- |
| Opening              | City overview                            | Period context           | This is a citywide story                    |
| Foundation           | Single node                              | Primary artifact         | A new practice appears                      |
| Parallel development | Multiple nodes appear together           | Distinct graphics        | Several mechanisms emerge simultaneously    |
| Infrastructure       | Earlier nodes remain; connections appear | Network graphic          | Individual scenes become connected          |
| Convergence          | Later node emphasized                    | Combined visual motifs   | Previously separate characteristics coexist |
| Ending               | Full route visible                       | Minimal additional media | The pattern is larger than any single place |

## 16. Check copy-map consistency

Before production, verify:

* the map does not imply causality the text rejects
* the prose does not describe movement the map contradicts
* section groupings match map reveals
* event locations correspond to the correct event boundaries
* icons and graphics represent the correct historical actors
* the final map reflects the route thesis

## 17. Avoid common presentation failures

### Famous-place tourism

Problem:

> The map becomes a tour of recognizable venues.

Fix:

Make each location visually express its historical function.

### Continuous route line by default

Problem:

A line can falsely imply chronological or causal continuity.

Fix:

Use clustering, simultaneous reveals, networks, or contrast where appropriate.

### One visual language for every stop

Problem:

Different historical mechanisms become visually indistinguishable.

Fix:

Use graphics that correspond to different forms of agency.

### Copy duplication

Problem:

The map shows exactly what the text already says.

Fix:

Give the map analytical work of its own.

### Visual overclaiming

Problem:

Graphics imply relationships not supported by evidence.

Fix:

Apply the same evidence discipline to visual connections as to written claims.

## Output

A completed final route copy + presentation treatment stage should produce:

### Final copy

* route title
* timeframe
* introduction
* final stop texts
* section transitions
* conclusion
* evidence-safe wording

### Presentation storyboard

* map state for each narrative moment
* location reveal logic
* conceptual graphics
* artifact recommendations
* connection graphics where supported
* ending map state

### Design rules

* route visual grammar
* treatment of parallel events
* treatment of networks
* treatment of convergence
* restrictions on unsupported arrows or route lines

## Stop Condition

This stage is complete when:

1. the route copy is concise and evidence-safe;
2. every stop advances the narrative;
3. the map has a clear analytical role;
4. visual sequencing matches the historical structure;
5. parallel events do not appear falsely sequential;
6. connections are visualized only when justified;
7. copy and map complement rather than duplicate one another;
8. the final experience communicates the thesis without requiring additional historical explanation.

The route is then ready for **implementation and production QA**.

## Principle

Evidence review asks:

> **Is the story historically defensible?**

Final route copy asks:

> **What is the clearest version of that story?**

Presentation treatment asks:

> **What should the user understand by seeing the story on the map rather than only reading it?**

The final route works when **copy, geography, and visual design all express the same historical argument**.

This brings the conceptual/research workflow to the production boundary: **the next step is implementation, followed by production QA rather than another narrative research stage.**
