# Cross-Stop Synthesis

## Goal

Combine the individually researched route events into one coherent historical argument.

This stage asks what the retained events prove **together**, how they relate to one another, and what final route structure best fits the evidence.

The purpose is to move from separate event dossiers to a unified narrative model before drafting prose.

## Inputs

A stable set of deep-researched route events containing:

* precise event boundaries
* verified or best-defensible locations
* key actors
* supported claims
* uncertainties
* narrative roles
* source evidence

## Core Principle

Do not assume that because events belong in the same route, they form a direct causal chain.

Connections between events may be:

* directly evidenced
* parallel
* structural
* contextual
* convergent
* interpretive

The synthesis should preserve those distinctions.

## Process

### 1. Extract the unique contribution of each event

For every retained event, summarize in one sentence:

> What does this event demonstrate that no other stop does as well?

Examples:

* new social-space model
* community ownership
* dancer-led innovation
* technological development
* infrastructure
* commercialization
* convergence
* backlash

If two events still make essentially the same contribution, reconsider whether both are necessary.

### 2. Compare events side by side

Create a compact comparison of:

* event date
* place
* actors
* historical mechanism
* route function
* strongest claim

The purpose is to see relationships that may not have been obvious when researching events individually.

### 3. Classify the relationship between events

Do not write every relationship as influence.

Useful categories include:

**Direct influence**

Evidence shows one actor, place, or practice influenced another.

**Institutional continuity**

The same people, organization, location, or infrastructure connects two events.

**Parallel development**

Similar or complementary changes occur independently or without demonstrated direct influence.

**Structural connection**

Events participate in the same larger system, such as distribution, nightlife, media, migration, or commerce.

**Contrast**

Two events represent different responses to the same conditions.

**Narrative convergence**

A later event contains several features previously seen separately, without requiring proof that all earlier events directly caused it.

**Contextual relationship**

The connection is useful for interpretation but should not be presented as a historical causal claim.

### 4. Separate evidence from synthesis

For every important transition, ask:

> Is this relationship documented, or are we constructing it as a narrative interpretation?

Documented connection:

> Actor A explicitly influenced Actor B.

Narrative synthesis:

> These simultaneous developments show several communities reshaping nightlife in different ways.

Both are legitimate, but they require different wording.

Avoid converting narrative convenience into historical causation.

### 5. Identify parallel developments

Events occurring around the same period may be more meaningful when presented together rather than sequentially.

Ask:

* Are different communities responding to similar conditions?
* Are different innovations emerging at the same time?
* Are several mechanisms contributing to a larger transformation?
* Does chronology falsely imply influence where only simultaneity is known?

Parallel presentation can prevent single-origin narratives.

### 6. Identify convergence points

Look for later events where several earlier mechanisms become visible together.

A convergence point may combine:

* community formation
* technology
* new performance practices
* infrastructure
* commercial systems
* spatial design

Treat convergence as an analytical relationship unless direct lineage is supported.

### 7. Identify changes in scale

Strong routes often shift scale.

For example:

* individual room
* neighborhood scene
* citywide network
* institutional infrastructure
* larger industry

These transitions can provide natural section boundaries.

### 8. Determine the route's true shape

Reassess the overall structure after synthesis.

Possible forms include:

**Linear transformation**
A sequence of documented changes.

**Parallel development**
Several processes evolve simultaneously.

**Branching**
One context produces multiple distinct directions.

**Network**
People, places, practices, and institutions exchange resources or ideas.

**Convergence**
Different processes become visible together in a later event.

**Contrast**
The route is structured around competing models.

Many routes may combine several of these.

Do not force chronological ordering to carry the entire narrative.

### 9. Build narrative sections

Group events according to historical function rather than giving every stop equal chapter weight.

A useful section might contain:

* one foundational event
* several parallel events
* one infrastructure event
* one later convergence

Each section should answer a distinct historical question.

For example:

**Section 1 — Emergence**
What changed first?

**Section 2 — Parallel experimentation**
Who changed the culture, and in what different ways?

**Section 3 — System formation**
How did isolated practices become connected?

**Section 4 — Maturity or convergence**
What did the developed form look like?

### 10. Define the transition logic

For every section transition, write the underlying reason the story moves forward.

Avoid transitions based only on date.

Weak:

> Three years later, another venue opened.

Stronger:

> The story now shifts from experiments inside individual spaces to the infrastructure connecting those spaces.

A route should progress conceptually as well as chronologically.

### 11. Rebuild the thesis from the cohort

Now rewrite the working thesis based only on what the retained events collectively support.

The thesis should:

* account for all core events
* avoid claims unsupported by the cohort
* reflect parallel or multiple developments when appropriate
* avoid false single-origin stories
* be specific enough to guide drafting

Every major phrase in the thesis should correspond to evidence somewhere in the route.

### 12. Check for overclaiming

Look specifically for language suggesting:

* a single origin
* inevitable progression
* direct influence without evidence
* total historical coverage
* one event representing an entire community
* one endpoint representing the completion of a genre

Narrow such claims where necessary.

Use language such as:

* contributed to
* helped establish
* developed alongside
* became one important model
* reveals
* demonstrates

when stronger causal language is not justified.

### 13. Identify remaining claim-level gaps

At this point, distinguish between:

**Structural problems**

A missing event or mechanism could change the route.

These require more research before drafting.

**Claim-level problems**

A specific detail, date, superlative, or attribution still needs corroboration.

These can often be handled through a narrow research task without reopening the route.

### 14. Confirm the route is ready for drafting

Before moving on, verify that the route now has:

* a stable cohort
* a clear thesis
* a defined narrative shape
* meaningful sections
* explicit transition logic
* clear event roles
* evidence-aware relationship types
* no unresolved structural gaps

## Suggested Synthesis Table

| Event   | Unique contribution           | Relationship to other events | Evidence type          | Narrative role  |
| ------- | ----------------------------- | ---------------------------- | ---------------------- | --------------- |
| Event A | Establishes new practice      | Direct influence on B        | Documented             | Foundation      |
| Event B | Develops practice further     | Influenced by A              | Documented             | Development     |
| Event C | Different community mechanism | Parallel to B                | Interpretive synthesis | Parallel strand |
| Event D | Creates infrastructure        | Connects multiple scenes     | Structural             | Bridge          |
| Event E | Combines earlier features     | Narrative convergence        | Mixed                  | Culmination     |

## Output

A completed cross-stop synthesis should produce:

* unique contribution of every event
* relationship classification between relevant events
* distinction between documented links and interpretation
* parallel-development findings
* convergence points
* changes in scale
* final route shape
* narrative sections
* transition logic
* final working thesis
* remaining claim-level uncertainties
* decision on readiness for narrative drafting

## Stop Condition

Cross-stop synthesis is complete when:

1. each event has a distinct role;
2. the relationships between events are explicitly classified;
3. unsupported causal links have been removed;
4. the route has a coherent structure beyond simple chronology;
5. section boundaries and transitions are clear;
6. the working thesis is supported by the retained cohort;
7. remaining uncertainties are claim-level rather than route-breaking.

The next stage is **narrative drafting**.

## Principle

Deep route research asks:

> **What can each event prove?**

Cross-stop synthesis asks:

> **What do these events prove together, and how should those relationships shape the story?**

Narrative drafting then asks:

> **How do we communicate that argument clearly, engagingly, and accurately?**
