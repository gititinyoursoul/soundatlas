The next step is the **minimum-sufficient cohort test**.

At this point, the goal is no longer to discover more candidates. It is to ask whether the **smallest defensible set of places/events** can already carry the full route.

For the disco topic, that means taking the strongest current candidates and testing:

* Does each candidate perform a unique narrative role?
* Does the set cover the major historical transitions?
* Are the key communities and mechanisms represented without tokenism?
* Does the geography remain meaningful?
* Are any candidates redundant?
* Can the thesis be explained from beginning to end with roughly **6–8 stops**?

The output should be a **provisional locked cohort**, for example:

> Loft → Black club-network candidate → St. Mary’s / Latin Hustle → Gallery → Record Pool → Paradise Garage

with Studio 54 or another candidate included only if it contributes something the others cannot.

The key question is:

> **What is the minimum route that still proves the story?**

If we can answer that convincingly, then we should stop discovering and move into **deep research on only those retained candidates**.
